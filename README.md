# 세종시 주차 허용·금지 구간 지도

세종특별자치시 도로안전표지 공공데이터(OpenAPI)를 불러와, **주차 가능 / 주차 금지 / 정차·주차 금지** 구간을 지도 위에서 확인하는 웹 서비스입니다.

- 데이터: 공공데이터포털 「세종특별자치시\_세종특별자치시 도로안전표지 조회 서비스」
- 엔드포인트: `https://apis.data.go.kr/5690000/sjRoadSign/sj_00000270`
- 일일 트래픽: 5,000건 (서버가 캐시와 조회 상한으로 보호합니다)

## 실행

```bash
cp .env.example .env      # 인증키·지도 키 설정 (인증키는 기본값이 이미 들어 있습니다)
npm start                 # http://localhost:3000
npm test                  # 오프라인 검증 (목 서버로 전 구간 테스트)
```

Node.js 18 이상이면 됩니다. 런타임 의존성이 없어 `npm install` 없이 바로 실행됩니다.

## 지도

국내 지도 품질(도로명·건물·일방통행 표기)을 우선해 다음 순서로 자동 선택합니다. `.env`에 키를 하나만 채우면 됩니다.

| 우선순위 | 공급자 | 환경변수 | 발급처 |
| --- | --- | --- | --- |
| 1 | 네이버 지도 | `NAVER_MAP_CLIENT_ID` | 네이버 클라우드 플랫폼 → Maps → Web Dynamic Map |
| 2 | 카카오맵 | `KAKAO_MAP_JS_KEY` | 카카오 개발자센터 → 내 애플리케이션 → JavaScript 키 |
| 3 | VWorld 국내 배경지도 | `VWORLD_KEY` | 국토교통부 VWorld 오픈API |
| 4 | OpenStreetMap | (없음) | 키 없이 동작하지만 국내 표기가 가장 약합니다 |

네이버·카카오는 콘솔에서 **Web 서비스 URL**에 `http://localhost:3000`(및 운영 도메인)을 등록해야 지도가 뜹니다. 등록하지 않으면 SDK가 인증 오류를 내고, 이 앱은 자동으로 다음 순위 지도로 내려갑니다.

Leaflet은 `public/vendor/leaflet/`에 포함해 두었습니다. 사내망·폐쇄망에서도 지도 틀은 뜨고, 외부로 나가는 요청은 배경지도 타일 하나로 줄어듭니다.

## 주차 구간 판정 방식

도로안전표지 데이터에서 주차 관련 표지를 골라내 세 가지로 분류합니다.

| 분류 | 의미 | 판정 근거 |
| --- | --- | --- |
| `no_stop_no_park` | 정차·주차 금지 | `정차·주차금지`, `주정차금지` / 규제표지 **218** |
| `no_park` | 주차 금지 | `주차금지` / 규제표지 **219** |
| `parking_allowed` | 주차 가능 | `주차장`, `노상주차장`, `주차허용` / 지시표지 **319** |
| `other` | 주차와 무관한 표지 | 위에 해당하지 않는 나머지 |

`정차·주차금지`는 `주차금지`를 문자열로 포함하므로 **반드시 먼저** 검사합니다. 표지명이 비어 있으면 표지번호(세 자리)로 한 번 더 판정합니다.

판정은 특정 필드명에 의존하지 않고 **레코드의 모든 문자열을 이어붙여** 검사합니다. 지자체 API는 필드명이 예고 없이 바뀌는 일이 있어, 한 필드만 보면 조용히 0건이 되기 때문입니다.

## 좌표 처리

`위도/경도`, `latitude/longitude`, `lat/lot`, `ycrd/xcrd` 등 알려진 이름을 먼저 찾고, 실패하면 **세종시 위경도 범위(36.35–36.78 N, 127.06–127.42 E)** 안에 들어오는 숫자쌍을 좌표로 추정합니다. 위경도가 뒤바뀌어 들어온 데이터도 범위로 교정합니다. 범위를 벗어나면 좌표 없음으로 처리해 엉뚱한 곳에 마커가 찍히지 않게 합니다.

## API

| 경로 | 설명 |
| --- | --- |
| `GET /api/signs` | 정규화·분류된 표지 목록. `category`, `q`, `bbox`, `mappableOnly`, `refresh=1` 지원 |
| `GET /api/schema` | **원본 응답에 실제로 어떤 필드가 오는지** 요약 (필드명·샘플값·좌표 인식 결과) |
| `GET /api/probe` | 1페이지 원본 응답 그대로 확인 (인증키는 가려서 표시) |
| `GET /api/config` | 프런트엔드가 쓸 지도 공급자 정보 |

`bbox`는 `minLng,minLat,maxLng,maxLat` 형식입니다.

### 데이터가 비어 보일 때

원본 응답 필드를 확인할 수 없는 상태에서 만든 구조라, 실제 필드가 예상과 다르면 다음 순서로 확인하세요.

1. `GET /api/schema` — 어떤 필드가 오는지, 좌표를 어디서 읽었는지 확인
2. 주차 관련 표지가 0건이면, 이 데이터셋에 표지 종류 필드가 없고 도로 구간 정보(노선·차로수)만 있는 경우입니다. 이때는 전량 `other`로 표시되며, `lib/normalize.js`의 `PARKING_RULES` 키워드를 실제 값에 맞춰 추가하면 됩니다.
3. `GET /api/probe` — 인증키·엔드포인트 문제인지, 응답 자체가 비어 있는지 구분

## 인증키 주의사항

포털은 Encoding 키와 Decoding 키를 함께 줍니다. 쿼리스트링에는 인코딩된 형태가 **정확히 한 번만** 들어가야 하며, 이 서버는 키에 `%2B` 같은 퍼센트 인코딩이 이미 있으면 그대로 쓰고, 없으면 한 번만 인코딩합니다. 이중 인코딩(`%252B`)으로 인증이 깨지는 흔한 문제를 막기 위한 처리입니다.

## 구조

```
server.js              HTTP 서버 · API 프록시 · 캐시
config.js              환경변수/.env 설정
lib/api.js             공공데이터 호출, 페이지 순회, JSON↔XML 자동 폴백
lib/xml.js             의존성 없는 최소 XML 파서
lib/normalize.js       좌표 탐지 · 주차 분류 · 스키마 요약
public/                지도 화면 (index.html, app.js, map.js, style.css)
public/vendor/leaflet  로컬 포함 Leaflet (폐쇄망 대응)
test/smoke.js          목 서버 기반 오프라인 검증
```
